## Repository settings

These settings back the contribution process. They live in GitHub, not in files, so check them when setting up or auditing the repository.

- [ ] **Private vulnerability reporting** enabled (Settings → Code security), as promised in [SECURITY.md](SECURITY.md)
- [ ] **Discussions** enabled, with categories for Q&A, Ideas and Announcements
- [ ] **`main` protected:** pull requests required, one approving review, required status checks (including `CLA`), linear history, no force pushes
- [ ] **Squash merging only**, with the pull request title as the commit message
- [ ] **Actions** allowed to create and approve comments and statuses (needed by the CLA workflow), and a `cla-signatures` branch left unprotected so the workflow can record signatures
- [ ] **Dependabot alerts and secret scanning** enabled
- [ ] Once code and CI exist (M0): Dependabot version updates and OpenSSF Scorecard
