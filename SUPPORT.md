# Getting help

| You want to… | Go to |
| --- | --- |
| Ask a question or discuss an idea | [GitHub Discussions](https://github.com/OstiaHQ/ostia/discussions) |
| Report a bug | [Issues](https://github.com/OstiaHQ/ostia/issues/new/choose), bug report template |
| Propose a design | An RFC pull request; see [docs/README.md](docs/README.md) |
| Report a security problem | Privately, as described in [SECURITY.md](SECURITY.md) |
| Report a Code of Conduct concern | alirezashateri7@gmail.com, as described in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

Ostia is maintained by volunteers; please be patient, and include your hardware and topology when asking about performance or transport problems.
